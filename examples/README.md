## Writing your own

- Start with `# Title`, then group steps under `## Block` headings.
- Add `×3` (or `x3`) at the end of a block heading to repeat it.
- Put the duration at the end of each step: `45s`, `2m`, `1:30`.
- Start a line with `~` for rest steps and `>` for a note under the previous step.
- A rest written after a repeated block belongs to that block, so give recovery between blocks its own `## Recover` block.
